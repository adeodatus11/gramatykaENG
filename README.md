# Gramatyka ENG

Osobista platforma do nauki angielskiej gramatyki (po polsku): 19 tematów, 152 ćwiczenia.

**Uruchomienie:** otwórz `index.html` w przeglądarce (bez instalacji, bez serwera).

- Teoria: kiedy używać, budowa, słowa-sygnały, przykłady PL/EN, typowe błędy Polaków
- Ćwiczenia: wybór i wpisywanie (rozumie skróty: `doesn't` = `does not`), wyjaśnienie po każdej odpowiedzi
- Mix losowych pytań, „Powtórka błędów”, ściągawka 12 czasów
- Postępy w `localStorage`

Treść edytujesz w `data.js` (`c(...)` = pytanie z wyborem, `t(...)` = wpisywanie).
